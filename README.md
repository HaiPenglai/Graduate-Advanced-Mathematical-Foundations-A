### 卡西欧计算器

由于老师考前明确说可以带计算器，所以建议带**卡西欧991CN**(高中物理竞赛专用计算器)。

可以进行分数计算和矩阵计算，但是不能进行含分数的矩阵计算。所以在以下场景建议使用卡西欧计算器而非手算：

- **复杂的分数计算**
- **整数矩阵乘法**
- **大概率算错了，但是硬要算一个奇怪的结果作为答案**
