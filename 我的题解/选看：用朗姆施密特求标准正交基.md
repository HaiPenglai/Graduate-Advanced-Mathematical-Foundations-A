下面我们通过一个具体的例题，再次动用你的 **“baseea”** 口诀。

---

### 例题：求零空间的标准正交基

**设矩阵 $A = [1, 1, 1, 1]$，求其零空间 $N(A)$ 的标准正交基。**

#### 第一步：求基础解系 ($\alpha_1, \alpha_2, \alpha_3$)
方程为 $x_1 + x_2 + x_3 + x_4 = 0$。自由变量为 $x_2, x_3, x_4$。
令自由变量分别取 $(1,0,0), (0,1,0), (0,0,1)$，得到基础解系：
$$\alpha_1 = \begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix}, \alpha_2 = \begin{bmatrix} -1 \\ 0 \\ 1 \\ 0 \end{bmatrix}, \alpha_3 = \begin{bmatrix} -1 \\ 0 \\ 0 \\ 1 \end{bmatrix}$$

---

#### 第二步：施密特正交化（动用 baseea 口诀）

我们需要求 $\varepsilon_1, \varepsilon_2, \varepsilon_3$。

**1. 求 $\varepsilon_1$：**
*   **$\beta_1 = \alpha_1$** = $[-1, 1, 0, 0]^T$
*   单位化：$\|\beta_1\| = \sqrt{2}$，得 **$\varepsilon_1 = \frac{1}{\sqrt{2}} \begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix}$**

**2. 求 $\varepsilon_2$（使用 baseea）：**
*   **口诀应用：** $\beta_2 = \text{b-a-s-e-e-a} \implies \beta_2 = \alpha_2 - \langle \varepsilon_1, \alpha_2 \rangle \varepsilon_1$
*   先算内积：$\langle \varepsilon_1, \alpha_2 \rangle = \frac{1}{\sqrt{2}} ((-1)(-1) + 1\cdot0 + 0\cdot1 + 0\cdot0) = \frac{1}{\sqrt{2}}$
*   代入公式：
    $$\beta_2 = \begin{bmatrix} -1 \\ 0 \\ 1 \\ 0 \end{bmatrix} - \frac{1}{\sqrt{2}} \cdot \left( \frac{1}{\sqrt{2}} \begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix} \right) = \begin{bmatrix} -1 \\ 0 \\ 1 \\ 0 \end{bmatrix} - \begin{bmatrix} -1/2 \\ 1/2 \\ 0 \\ 0 \end{bmatrix} = \begin{bmatrix} -1/2 \\ -1/2 \\ 1 \\ 0 \end{bmatrix}$$
*   为了方便单位化，取方向向量 $\beta_2' = [-1, -1, 2, 0]^T$，其长度为 $\sqrt{6}$。
*   得 **$\varepsilon_2 = \frac{1}{\sqrt{6}} \begin{bmatrix} -1 \\ -1 \\ 2 \\ 0 \end{bmatrix}$**

**3. 求 $\varepsilon_3$（强化版 baseea）：**
*   **口诀应用：** $\beta_3 = \alpha_3 - \sum \langle \varepsilon_j, \alpha_3 \rangle \varepsilon_j \implies \beta_3 = \alpha_3 - \langle \varepsilon_1, \alpha_3 \rangle \varepsilon_1 - \langle \varepsilon_2, \alpha_3 \rangle \varepsilon_2$
*   先算内积：
    *   $\langle \varepsilon_1, \alpha_3 \rangle = \frac{1}{\sqrt{2}} (1 + 0 + 0 + 0) = \frac{1}{\sqrt{2}}$
    *   $\langle \varepsilon_2, \alpha_3 \rangle = \frac{1}{\sqrt{6}} (1 + 0 + 0 + 0) = \frac{1}{\sqrt{6}}$
*   代入公式：
    $$\beta_3 = \begin{bmatrix} -1 \\ 0 \\ 0 \\ 1 \end{bmatrix} - \frac{1}{2} \begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix} - \frac{1}{6} \begin{bmatrix} -1 \\ -1 \\ 2 \\ 0 \end{bmatrix} = \begin{bmatrix} -1 + 1/2 + 1/6 \\ 0 - 1/2 + 1/6 \\ 0 - 0 - 2/6 \\ 1 - 0 - 0 \end{bmatrix} = \begin{bmatrix} -1/3 \\ -1/3 \\ -1/3 \\ 1 \end{bmatrix}$$
*   取方向向量 $\beta_3' = [-1, -1, -1, 3]^T$，其长度为 $\sqrt{1+1+1+9} = \sqrt{12} = 2\sqrt{3}$。
*   得 **$\varepsilon_3 = \frac{1}{2\sqrt{3}} \begin{bmatrix} -1 \\ -1 \\ -1 \\ 3 \end{bmatrix}$**

---

### 结论
该矩阵零空间的一组标准正交基为：
$$\left\{ \frac{1}{\sqrt{2}} \begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix}, \frac{1}{\sqrt{6}} \begin{bmatrix} -1 \\ -1 \\ 2 \\ 0 \end{bmatrix}, \frac{1}{2\sqrt{3}} \begin{bmatrix} -1 \\ -1 \\ -1 \\ 3 \end{bmatrix} \right\}$$

### 复盘口诀 baseea 的威力：
在计算 $\beta_3$ 这种复杂步骤时，最容易乱的是“减去哪几个项”以及“内积里放谁”。
*   **b**: 我要算的 $\beta_3$
*   **a**: 当前还没处理的原始向量 $\alpha_3$
*   **s**: 减去所有前面的投影之和 ($\sum$)
*   **ee**: 已经正交化好的单位向量 $\varepsilon_1, \varepsilon_2$（一个在内积里提供方向参考，一个在外面提供方向分量）
*   **a**: 依然是正在处理的原始向量 $\alpha_3$（放在内积里）

**记忆要点：** 只有 $\alpha_i$ 是随着步骤改变的新输入，所有的 $\varepsilon$ 都是之前步骤攒下来的“成果”。通过 **baseea**，你永远不会忘记要把正在处理的那个 $\alpha$ 塞进内积里去扣掉投影。
